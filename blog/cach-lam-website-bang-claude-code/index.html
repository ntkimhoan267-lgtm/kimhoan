Mình không học lập trình. Nhưng cả website này, từ trang chủ, trang dịch vụ visa đến blog song ngữ, đều do mình làm bằng Claude Code: mình nói bằng tiếng Việt, Claude viết code, mình duyệt từng phần. I never studied programming. Yet this whole site, from the homepage and the visa service page to the bilingual blog, was built with Claude Code: I describe what I want in plain Vietnamese, Claude writes the code, and I review every part.

Bài này là đúng quy trình mình dùng, chia thành 9 bước. Mỗi bước có prompt mẫu để bạn bấm sao chép, và cuối bài có bộ skill để Claude Code tự làm theo quy trình đó trên máy bạn. This post is the exact process I use, split into 9 steps. Each step has a sample prompt you can copy with one click, and at the end there is a skill pack that makes Claude Code follow the same process on your own computer.

Câu trả lời ngắn Short answer

Cài Claude Code, mô tả website bằng lời, để Claude viết code, rồi đưa lên GitHub Pages miễn phí. Bạn cần một tài khoản Claude trả phí và khoảng một buổi chiều cho website đầu tiên. Không cần biết code, nhưng cần biết rõ mình muốn gì và chịu khó duyệt từng phần. Install Claude Code, describe the site in plain words, let Claude write the code, then publish it free on GitHub Pages. You need a paid Claude account and about an afternoon for your first site. No coding required, but you do need to know what you want and review each part carefully.

Cần chuẩn bị gì? What you need

Claude Code là trợ lý lập trình của Anthropic. Khác với khi chat trên claude.ai, Claude Code làm việc trực tiếp trong thư mục trên máy bạn: tự tạo file, viết code, chạy lệnh, mở trình duyệt kiểm tra. Bạn chỉ cần nói việc cần làm. Claude Code is Anthropic's coding assistant. Unlike chatting on claude.ai, Claude Code works directly in a folder on your computer: it creates files, writes code, runs commands and checks the result in a browser. You just say what needs doing.

Bước 1: Cài Claude Code Step 1: Install Claude Code

Mở Terminal (trên Mac: nhấn Cmd + Space, gõ "Terminal"). Dán lệnh dưới rồi nhấn Enter. Lệnh không hiện tiến độ khi tải, cứ chờ tới khi xong. Open Terminal (on a Mac: press Cmd + Space and type "Terminal"). Paste the command below and press Enter. It shows no progress while downloading, so just wait for it to finish.

macOS / LinuxmacOS / Linux
curl -fsSL https://claude.ai/install.sh | bash

Trên Windows, mở PowerShell và dán lệnh này. Nên cài thêm Git for Windows để Claude Code chạy lệnh ổn định hơn. On Windows, open PowerShell and paste this instead. Installing Git for Windows as well helps Claude Code run commands reliably.

Windows PowerShellWindows PowerShell
irm https://claude.ai/install.ps1 | iex

Cài xong, mở cửa sổ Terminal mới, tạo thư mục cho website và khởi động Claude Code. Lần đầu chạy, Claude Code mở trình duyệt để bạn đăng nhập tài khoản Claude. Once installed, open a new terminal window, create a folder for the site and start Claude Code. On first run, Claude Code opens your browser so you can sign in to your Claude account.

Lệnh TerminalTerminal command
claude --version
mkdir website-cua-toi
cd website-cua-toi
claude

Nếu Terminal báo không tìm thấy lệnh claude, đóng hẳn Terminal rồi mở lại. Vẫn lỗi thì xem trang khắc phục sự cố trong tài liệu chính thức ở cuối bài. If the terminal says claude is not found, quit the terminal completely and reopen it. If it still fails, see the troubleshooting page in the official docs linked at the end.

Bước 3: Viết brief cùng Claude Step 3: Write the brief with Claude

Đây là bước quyết định website đẹp hay không, và là bước người mới hay bỏ qua nhất. Claude chỉ làm tốt khi biết rõ website cho ai và họ cần làm gì. Thay vì tự viết một đoạn mô tả dài, hãy để Claude phỏng vấn bạn. This step decides whether the site turns out well, and it is the one beginners skip most. Claude only does good work when it knows who the site is for and what they need to do. Instead of writing a long description yourself, let Claude interview you.

Prompt mẫuSample prompt
Mình muốn làm website [loại website: portfolio cá nhân / giới thiệu tiệm bánh / landing page khoá học].
Trước khi viết code, hãy phỏng vấn mình từng câu một để làm rõ:
1. Website dành cho ai, khi vào trang họ cần làm gì nhất?
2. Có những trang hoặc mục nào?
3. Thông tin liên hệ thật (Zalo, điện thoại, địa chỉ).
4. Màu sắc, phong cách, website tham khảo mình thích.
5. Nội dung và hình ảnh mình đã có.
Hỏi xong, tóm tắt vào file BRIEF.md để mình duyệt. Chưa viết code.
I want to build a [type of site: personal portfolio / bakery website / course landing page].
Before writing any code, interview me one question at a time to clarify:
1. Who is the site for, and what is the one thing they should do on it?
2. Which pages or sections it needs.
3. My real contact details (phone, messaging app, address).
4. Colours, style, and sites I like for reference.
5. What content and photos I already have.
When you are done, summarise everything in BRIEF.md for me to review. Do not write code yet.

Đã cài bộ skill thì chỉ cần gõ /website-brief kèm một câu mô tả. Claude sẽ tự hỏi đủ 6 câu theo thứ tự. With the skill pack installed, just type /website-brief followed by one sentence. Claude asks all six questions in order.

Mẹo: chép ảnh logo và ảnh sản phẩm vào thư mục images/ trong thư mục website ngay từ bây giờ. Claude sẽ thấy và dùng ảnh thật thay vì ảnh minh hoạ.Tip: copy your logo and product photos into an images/ folder inside the project now. Claude will find them and use real photos instead of placeholders.

Bước 4: Lên kế hoạch bằng Plan mode Step 4: Plan with Plan mode

Nhấn Shift + Tab vài lần cho tới khi dòng dưới cùng hiện plan mode on. Ở chế độ này Claude chỉ đọc và lập kế hoạch, không sửa file nào. Bạn duyệt kế hoạch trước, rồi mới cho Claude làm. Press Shift + Tab a few times until the bottom line shows plan mode on. In this mode Claude only reads and plans; it changes no files. You approve the plan first, then let Claude build.

Prompt mẫuSample prompt
Đọc BRIEF.md và lên kế hoạch xây website:
- Cấu trúc thư mục và danh sách file
- Bố cục từng mục trên trang chủ, từ trên xuống
- Màu, font Google Fonts, khoảng cách dùng chung
- Website tĩnh HTML/CSS/JS thuần, không framework, để đưa lên GitHub Pages miễn phí
- Làm cho điện thoại trước, rồi mới tới máy tính
Cuối kế hoạch, liệt kê những gì mình còn phải cung cấp.
Read BRIEF.md and plan the website:
- Folder structure and list of files
- Layout of each homepage section, top to bottom
- Shared colours, Google Fonts and spacing
- A static HTML/CSS/JS site with no framework, so it can be hosted free on GitHub Pages
- Mobile first, then desktop
End the plan with a list of anything I still need to provide.

Đọc kỹ kế hoạch. Muốn đổi gì thì cứ nói, ví dụ "bỏ mục bản đồ, thêm mục khách hàng nói gì". Khi ưng, chọn đồng ý để Claude bắt đầu làm. Read the plan carefully. Ask for changes in plain words, for example "drop the map section and add a testimonials section". When you are happy, approve it and Claude starts building.

Bước 5: Dựng trang và tạo CLAUDE.md Step 5: Build the page and create CLAUDE.md

Prompt mẫuSample prompt
Kế hoạch ổn. Bắt đầu dựng trang chủ.
- Viết nội dung thật từ BRIEF.md, không dùng lorem ipsum. Chỗ nào thiếu thông tin thì ghi [CẦN ĐIỀN].
- Dùng ảnh trong thư mục images/, nén nhẹ nếu ảnh quá nặng.
- Xong thì chỉ mình cách mở trang trên máy để xem.
The plan looks good. Start building the homepage.
- Write real copy from BRIEF.md, no lorem ipsum. Where information is missing, write [TO FILL].
- Use the photos in images/ and compress any that are too heavy.
- When done, tell me how to open the page on my computer.

Trong lúc làm, Claude sẽ hỏi xin phép trước khi tạo file hay chạy lệnh. Đọc lướt rồi chọn Yes. Xong việc, mở file index.html bằng trình duyệt là thấy website. While it works, Claude asks permission before creating files or running commands. Skim each request and choose Yes. When it finishes, open index.html in your browser to see the site.

Tạo CLAUDE.md: "trí nhớ" của dự ánCreate CLAUDE.md: the project's memory

Mỗi lần mở Claude Code là một cuộc trò chuyện mới. File CLAUDE.md ở thư mục gốc là thứ Claude luôn đọc đầu tiên, nên mọi quy tắc của dự án nên nằm ở đây. Gõ /init để Claude tự tạo, rồi bổ sung: Every Claude Code session starts fresh. The CLAUDE.md file in the project root is the first thing Claude reads, so every project rule belongs there. Type /init to have Claude create it, then add to it:

Prompt mẫuSample prompt
Bổ sung vào CLAUDE.md các quy tắc của dự án:
- Màu và font thương hiệu, logo luôn dùng file images/logo.png
- Giọng văn: [thân thiện, xưng "mình – bạn" / trang trọng, xưng "chúng tôi – quý khách"]
- Không bịa thông tin thật như giá, số điện thoại, địa chỉ
- Luôn kiểm tra trên điện thoại trước khi báo xong
Add the project rules to CLAUDE.md:
- Brand colours and fonts; always use images/logo.png for the logo
- Tone of voice: [friendly and casual / formal]
- Never invent real details such as prices, phone numbers or addresses
- Always check the mobile layout before reporting a task as done

Trong bộ skill có sẵn một file CLAUDE.md mẫu, bạn chỉ cần điền vào chỗ trống. The skill pack includes a ready-made CLAUDE.md template; just fill in the blanks.

Bật lưu lịch sử bằng git ngay từ bây giờTurn on git history right now

Git ghi lại từng phiên bản của website, giống nút "hoàn tác" cho cả dự án. Bật nó ngay sau khi có trang đầu tiên, để mọi lần sửa ở bước 6 trở đi đều có đường lui. Git records every version of your site, like an undo button for the whole project. Turn it on as soon as the first page exists, so every change from step 6 onwards can be rolled back.

Prompt mẫuSample prompt
Khởi tạo git cho dự án này, tạo file .gitignore phù hợp và commit bản đầu tiên.
Từ giờ, mỗi khi làm xong một phần mình duyệt, hãy commit với lời nhắn tiếng Việt ngắn gọn mô tả thay đổi.
Initialise git for this project, create a suitable .gitignore and commit the first version.
From now on, whenever you finish a part I have approved, commit it with a short message describing the change.

Lỡ sửa hỏng, chỉ cần nói "quay lại bản commit trước". Muốn Claude nhớ thói quen này lâu dài, thêm dòng "commit sau mỗi phần đã duyệt" vào CLAUDE.md. If a change breaks something, just say "go back to the previous commit". To make this a lasting habit, add "commit after each approved part" to CLAUDE.md.

Bước 6: Sửa theo góp ý Step 6: Revise from feedback

Bản đầu tiên hiếm khi đúng ý ngay. Cách sửa hiệu quả nhất là góp ý cụ thể, đánh số, và dặn giữ nguyên phần còn lại. Bạn cũng có thể kéo thả ảnh chụp màn hình vào cửa sổ Claude Code để chỉ đúng chỗ cần sửa. The first version is rarely exactly right. The most effective way to revise is specific, numbered feedback, plus an instruction to leave everything else alone. You can also drag a screenshot into the Claude Code window to point at the exact spot.

Prompt mẫuSample prompt
Sửa theo góp ý:
1. Tiêu đề phần đầu ngắn lại, nói rõ mình làm gì cho ai.
2. Nút liên hệ đổi thành nhắn Zalo số [số điện thoại].
3. Mục dịch vụ xếp thành thẻ: 1 cột trên điện thoại, 3 cột trên máy tính.
Chỉ sửa những chỗ này, giữ nguyên phần còn lại.
Revise as follows:
1. Shorten the hero headline so it says clearly what I do and for whom.
2. Change the contact button to open a chat on [messaging app] with [phone number].
3. Lay out the services as cards: 1 column on mobile, 3 on desktop.
Change only these things and leave everything else as it is.

Nguyên tắc của mình: mỗi lần chỉ sửa 2–4 điểm. Góp ý dồn 15 điểm một lúc thì dễ bị sót, và khó biết thay đổi nào làm hỏng chỗ nào.My rule: ask for 2–4 changes at a time. Fifteen changes in one go means some get missed, and it is hard to tell which change broke what.

Form liên hệ: website tĩnh không tự gửi đượcContact forms: a static site cannot send them on its own

GitHub Pages chỉ chạy website tĩnh, không có máy chủ xử lý dữ liệu. Vì vậy một form "Gửi tin nhắn" tự viết sẽ không gửi đi đâu cả, dù trông vẫn bình thường. Có ba cách thay thế: GitHub Pages only serves static files, with no server to process data. A hand-built "Send message" form therefore goes nowhere, even though it looks fine. There are three alternatives:

  • Nút nhắn tin trực tiếp: Zalo, Messenger, gọi điện. Đơn giản nhất và hợp với khách Việt.Direct message buttons: Zalo, Messenger or a call link. The simplest option, and what Vietnamese customers expect.
  • Google Forms: miễn phí, câu trả lời tự vào Google Sheets. Gắn bằng nút link hoặc nhúng vào trang.Google Forms: free, with responses landing in Google Sheets. Link to it from a button or embed it on the page.
  • Dịch vụ nhận form như Formspree: giữ form đẹp trên website, tin nhắn gửi về email. Gói miễn phí có giới hạn số lượt gửi mỗi tháng.A form service such as Formspree: keeps a styled form on your site and emails you each message. The free tier caps monthly submissions.
Prompt mẫuSample prompt
Website này chạy trên GitHub Pages nên không có máy chủ xử lý form.
Làm phần liên hệ theo cách: [nút Zalo số ... và Messenger / nút mở Google Form ở link ... / form gửi qua Formspree, mình sẽ đưa mã form].
Bỏ mọi form không gửi được, và thử bấm từng nút xem có mở đúng không.
This site runs on GitHub Pages, so there is no server to process forms.
Build the contact section using: [a Zalo button for ... and a Messenger button / a button opening my Google Form at ... / a form sent through Formspree, I will give you the form ID].
Remove any form that cannot actually send, and test that each button opens the right place.

Bước 7: Làm SEO Step 7: Set up SEO

SEO giúp Google hiểu website của bạn, và giúp link chia sẻ lên Facebook, Zalo hiện ảnh và tiêu đề đẹp. Phần này nhiều chi tiết kỹ thuật nhưng bạn không cần nhớ, chỉ cần đưa Claude tên miền và từ khoá. SEO helps Google understand your site, and makes links shared on Facebook or messaging apps show a proper image and title. It is full of technical details, but you do not need to remember them: just give Claude your domain and keywords.

Prompt mẫuSample prompt
Làm SEO cơ bản cho toàn bộ website:
- Thẻ title và meta description riêng cho từng trang, có từ khoá [từ khoá chính]
- Thẻ Open Graph để chia sẻ Facebook, Zalo hiện ảnh (ảnh 1200×630)
- Dữ liệu có cấu trúc JSON-LD phù hợp với loại website
- favicon, sitemap.xml, robots.txt
- Thuộc tính alt có ý nghĩa cho mọi ảnh
Tên miền của mình là [tenmien.com].
Set up basic SEO for the whole site:
- A unique title and meta description per page, using the keyword [main keyword]
- Open Graph tags so shared links show an image (1200×630)
- Structured data (JSON-LD) that fits the type of site
- favicon, sitemap.xml, robots.txt
- Meaningful alt text on every image
My domain is [yourdomain.com].

Với bộ skill, gõ /seo-setup là đủ. Claude sẽ hỏi tên miền và từ khoá nếu chưa biết. With the skill pack, typing /seo-setup is enough. Claude asks for the domain and keywords if it does not have them.

Optional, but worth adding from day one so you have numbers to compare later. Create a free Google Analytics account, add a Web data stream for your domain, and copy the measurement ID, which looks like G-XXXXXXXXXX.

Prompt mẫuSample prompt
Gắn Google Analytics 4 với mã đo lường [G-XXXXXXXXXX] vào mọi trang của website. Đặt đoạn mã trong thẻ head, không làm chậm trang, rồi chỉ mình cách kiểm tra mã đã chạy chưa.
Add Google Analytics 4 with measurement ID [G-XXXXXXXXXX] to every page of the site. Put the snippet in the head without slowing the page down, then show me how to check that it is working.

Bước 8: Kiểm tra trên 3 cỡ màn hình Step 8: Test on three screen sizes

Phần lớn khách sẽ xem website trên điện thoại, nên đừng chỉ nhìn trên máy tính. Claude Code có thể tự mở trình duyệt ẩn, chụp màn hình ở nhiều kích thước, tìm lỗi và sửa. Most visitors will see your site on a phone, so do not judge it on a laptop alone. Claude Code can open a headless browser, take screenshots at several sizes, find problems and fix them.

Cần Node.js cho bước này. Phần kiểm tra tự động dùng Playwright, mà Playwright chạy trên Node.js. Bộ cài Claude Code không kèm Node.js. Gõ lệnh dưới trong Terminal: hiện số phiên bản là đã có, báo lỗi thì tải bản LTS tại nodejs.org rồi cài như phần mềm bình thường.This step needs Node.js. The automated checks use Playwright, which runs on Node.js, and the Claude Code installer does not include it. Run the command below in a terminal: a version number means you have it; an error means you should download the LTS version from nodejs.org and install it like any other app.

Kiểm tra Node.jsCheck for Node.js
node --version

Có Node.js rồi thì Claude tự cài Playwright và trình duyệt kiểm tra khi chạy prompt dưới, bạn chỉ cần đồng ý khi được hỏi. Once Node.js is installed, Claude installs Playwright and its test browser itself when you run the prompt below; just approve when asked.

Prompt mẫuSample prompt
Kiểm tra toàn bộ website trước khi đưa lên mạng:
1. Chụp màn hình ở 3 cỡ: điện thoại 375px, tablet 768px, máy tính 1280px
2. Tìm chỗ bị tràn ngang, chữ chồng nhau, ảnh vỡ
3. Kiểm tra mọi link và nút đều hoạt động
4. Báo lỗi JavaScript nếu có
Liệt kê lỗi tìm được, sửa, rồi kiểm tra lại lần nữa.
Test the whole site before it goes live:
1. Take screenshots at 3 sizes: phone 375px, tablet 768px, desktop 1280px
2. Look for horizontal overflow, overlapping text and broken images
3. Check that every link and button works
4. Report any JavaScript errors
List what you find, fix it, then run the checks again.

Bước 9: Đưa website lên mạng Step 9: Put the site online

GitHub Pages cho bạn đưa website tĩnh lên mạng miễn phí, có HTTPS, và gắn được tên miền riêng. Đây cũng là cách iamkimhoan.vn đang chạy. GitHub Pages hosts static websites for free, with HTTPS, and supports custom domains. It is also how iamkimhoan.vn runs.

Trước tiên: đăng nhập GitHub trên máy một lầnFirst: sign in to GitHub on your computer once

Lần đầu đẩy code lên, GitHub đòi xác thực và không nhận mật khẩu tài khoản. Cách dễ nhất là cài GitHub CLI rồi đăng nhập qua trình duyệt. Làm một lần, từ đó Claude đẩy code thoải mái. The first time you push, GitHub asks you to authenticate and will not accept your account password. The easiest fix is to install the GitHub CLI and sign in through your browser. Do it once and Claude can push freely from then on.

macOS (cần Homebrew)macOS (needs Homebrew)
brew install gh
Windows PowerShellWindows PowerShell
winget install --id GitHub.cli
Đăng nhậpSign in
gh auth login

Khi được hỏi, chọn lần lượt: GitHub.com, giao thức HTTPS, đồng ý dùng tài khoản GitHub cho Git, rồi Login with a web browser. Terminal hiện một mã 8 ký tự, bạn dán mã đó vào trang GitHub vừa mở là xong. Mac chưa có Homebrew thì nhờ Claude cài giúp, hoặc tải bộ cài GitHub CLI tại cli.github.com. When prompted, choose GitHub.com, the HTTPS protocol, agree to use your GitHub credentials for Git, then Login with a web browser. The terminal shows an 8-character code; paste it into the GitHub page that opens and you are done. If your Mac has no Homebrew, ask Claude to install it, or download the GitHub CLI installer from cli.github.com.

Lưu ý quyền riêng tư: với tài khoản GitHub miễn phí, GitHub Pages chỉ chạy trên repository Public, nghĩa là ai cũng xem được toàn bộ code và file trong thư mục dự án. Đừng để giấy tờ, file khách hàng, mật khẩu hay mã API trong thư mục website.Privacy note: on a free GitHub account, GitHub Pages only works with a Public repository, which means anyone can see all the code and files in your project folder. Never keep documents, client files, passwords or API keys in the website folder.

Prompt mẫuSample prompt
Đưa website lên GitHub Pages:
1. Kiểm tra mọi thay đổi đã được commit
2. Hướng dẫn mình từng bước tạo repository trên GitHub và đẩy code lên
3. Bật GitHub Pages từ nhánh main
4. Gắn tên miền [tenmien.com]: tạo file CNAME và cho mình danh sách bản ghi DNS cần thêm ở nhà cung cấp tên miền
Giải thích ngắn gọn từng bước, vì mình không rành kỹ thuật.
Publish the site on GitHub Pages:
1. Check that every change has been committed
2. Walk me through creating a repository on GitHub and pushing the code
3. Turn on GitHub Pages from the main branch
4. Connect my domain [yourdomain.com]: create the CNAME file and give me the DNS records to add at my domain registrar
Keep each step short, I am not technical.

Claude sẽ đưa bạn 4 bản ghi A và 1 bản ghi CNAME để thêm ở trang quản lý tên miền. DNS có thể mất vài giờ mới nhận. Khi GitHub báo tên miền đã đúng, bật Enforce HTTPS trong mục Settings → Pages. Claude gives you four A records and one CNAME record to add in your domain registrar's dashboard. DNS can take a few hours to update. Once GitHub confirms the domain, switch on Enforce HTTPS under Settings → Pages.

Mở thử trên điện thoại thậtTry it on a real phone

Ảnh chụp từ trình duyệt ẩn ở bước 8 không thay được việc tự bấm thử. Mở website trên điện thoại của bạn, bấm từng nút liên hệ, mở menu, gửi link cho một người bạn qua Zalo xem ảnh chia sẻ có hiện không. Thấy chỗ nào lạ thì chụp màn hình và kéo vào Claude Code. Screenshots from the headless browser in step 8 cannot replace tapping through it yourself. Open the site on your own phone, tap every contact button, open the menu, and send the link to a friend on a messaging app to check the share preview. If anything looks off, take a screenshot and drag it into Claude Code.

Cuối cùng: báo cho Google biếtFinally: tell Google about your site

Vào Google Search Console, thêm website và chọn xác minh bằng thẻ HTML. Dán thẻ đó cho Claude: Open Google Search Console, add your site and choose HTML tag verification. Paste the tag to Claude:

Prompt mẫuSample prompt

Từ giờ, mỗi lần muốn sửa website: mở Claude Code trong thư mục dự án, nói việc cần sửa, kiểm tra, rồi bảo Claude đẩy lên. Website tự cập nhật sau 1–2 phút. From now on, to change the site: open Claude Code in the project folder, describe the change, test it, then ask Claude to push. The live site updates within a minute or two.

  • Để AI tự điền thông tin thật. Giá, số điện thoại, địa chỉ phải do bạn đưa. Luôn đọc lại nội dung trước khi đăng.Letting AI fill in real details. Prices, phone numbers and addresses must come from you. Always proofread before publishing.

Câu hỏi thường gặp Frequently asked questions

Làm website bằng Claude Code có cần biết code không?Do I need to know how to code to build a website with Claude Code?

Không. Bạn mô tả bằng tiếng Việt, Claude viết code. Bạn cần biết rõ mình muốn gì, đọc kỹ kế hoạch Claude đưa ra và kiểm tra kết quả trên trình duyệt. Biết một chút HTML sẽ giúp bạn góp ý nhanh hơn, nhưng không bắt buộc. No. You describe what you want in plain language and Claude writes the code. You do need to know what you want, read the plans Claude proposes and check the result in a browser. A little HTML helps you give faster feedback, but it is not required.

Làm website bằng Claude Code tốn bao nhiêu tiền?How much does it cost to build a website with Claude Code?

Bạn cần một gói Claude trả phí từ Pro trở lên, hoặc tài khoản Claude Console trả theo lượt dùng. GitHub Pages miễn phí. Tên miền riêng là tuỳ chọn, trả phí hằng năm cho nhà cung cấp tên miền. You need a paid Claude plan (Pro or higher) or a pay-as-you-go Claude Console account. GitHub Pages hosting is free. A custom domain is optional and billed yearly by your domain registrar.

Claude Code khác gì so với chat với Claude trên claude.ai?How is Claude Code different from chatting with Claude on claude.ai?

Khi chat, Claude chỉ đưa code cho bạn tự chép vào file. Claude Code làm việc trực tiếp trong thư mục trên máy bạn: tự tạo và sửa file, chạy lệnh, chụp màn hình kiểm tra, và đẩy code lên GitHub. In a chat, Claude hands you code to copy into files yourself. Claude Code works directly in a folder on your computer: it creates and edits files, runs commands, takes screenshots to check its work and pushes code to GitHub.

Website làm bằng Claude Code có thuộc về mình không?Do I own a website built with Claude Code?

Có. Toàn bộ code nằm trong thư mục trên máy bạn và trong tài khoản GitHub của bạn. Bạn có thể chuyển sang dịch vụ lưu trữ khác bất cứ lúc nào, vì đây là website HTML tĩnh, không phụ thuộc nền tảng nào. Yes. All the code lives in a folder on your computer and in your own GitHub account. Because it is a plain static HTML site, you can move it to any other host at any time.

Website làm bằng Claude Code trên GitHub Pages có làm được form liên hệ không?Can a Claude Code website on GitHub Pages have a contact form?

Không theo cách thông thường, vì GitHub Pages chỉ chạy website tĩnh, không có máy chủ nhận dữ liệu. Thay vào đó, dùng nút Zalo hoặc Messenger, liên kết tới Google Forms, hoặc một dịch vụ nhận form như Formspree để tin nhắn gửi về email. Not in the usual way, because GitHub Pages only serves static files and has no server to receive data. Use Zalo or Messenger buttons, a link to Google Forms, or a form service such as Formspree that emails you each message instead.
